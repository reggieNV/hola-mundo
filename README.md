# Hola Mundo

Este repositorio contiene un programa básico de Hola Mundo desarrollado en Python.

## Lenguaje utilizado

- Python

## Ramas

- `main`: versión principal del programa.
- `dev`: rama utilizada para desarrollo.
- `testing`: rama utilizada para realizar pruebas.

## Ejecución

Para ejecutar el programa:

```bash
python hola_mundo.py
```
